# Retention-Rate-Cohort-Analysis
PL: 
Ocena wskaźnika utrzymania użytkowników (Retention Rate) przy użyciu Arkuszy Google i języka SQL w oparciu o analizę kohortową (Cohort Analysis).
- Pracowałem z bazą danych w celu przygotowania tabel kohortowych
- Oczyszczałem i przekształcałem dane w różnych formatach za pomocą języka SQL
- Obliczałem kohorty użytkowników i ich staż w firmie
- Tworzyłem interaktywne tabele kohortowe w Arkuszach Google
- Analizowałem wskaźnik retencji użytkowników (Retention Rate) dla różnych źródeł pozyskiwania
- Porównywałem zachowania użytkowników pozyskanych w ramach promocji i użytkowników organicznych

Eng:  Measuring User Retention Using Google Sheets and SQL Based on Cohort Analysis.
- Worked with a database to generate cohort tables
- Cleaned and transformed data in various formats using SQL
- Calculated user cohorts and their tenure at the company
- Built interactive cohort tables in Google Sheets
- Analyzed user retention rates for different acquisition sources
- Compared the behavior of promotional users and organic users

UA: Оцінка утримання користувачів (Retention Rate) методами Google Sheets та SQL на основі когортного аналізу (Cohort Analysis).
- Працював з базою даних для підготовки когортних таблиць
- Очищав та трансформував дати у різних форматах за допомогою SQL
- Розраховував когорти користувачів та їхній стаж у компанії
- Будував інтерактивні когортні таблиці у Google Sheets
- Аналізував утримання користувачів (Retention Rate) для різних джерел залучення
- Порівнював поведінку промо-користувачів та органічних користувачів
